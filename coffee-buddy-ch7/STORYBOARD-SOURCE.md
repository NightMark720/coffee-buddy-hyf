# Coffee Buddy × Yeema One — Chapter 7: "Invented on the spot"
## 分镜脚本 · 时间轴结构版（对齐 UI V1.1 卡片逻辑）

> 本章目标：**创意创新饮品**——AI 结合天气、心情、手上物料与口味档案，现场创作全新配方并制成饮品。
> 全部界面文案为英文（Figma 中文需出英文版）。无配音——文字 + 音效。
> ★ 本章飞出动效：**原料词落杯、调制成型、缩嵌进配方卡**——全系列动效密度最高的一章。

| 项目 | 值 |
|------|-----|
| 画布 | 1080 × 1920（9:16） |

## 3. 交接备注（给 Codex）

1. 720 帧单一 composition；分层节点：0 / 1.2 / 3.8 / 4.4 / 6.2 / 8.0 / 9.2 / 12.4 / 13.8 / 15.4 / 19.4 / 21.0 / 22.4 / 24.0。
2. 调酒段（9.2–12.4s）聊天 UI 不消失，仅压暗 15%；玻璃杯独立于卡片层，缩嵌终点 = 配方卡图标位的精确坐标。
3. 配方卡图标位从入场起就是空槽（虚线占位），缩嵌后实杯替换——观众回看时能发现这个伏笔。
4. 分层动效遵循物理：汤力水在下、浓缩在上注入，橙片带旋转；不追求照片真实，保持品牌插画的色块感。
5. 文案逐字锁定；帧驱动定时；机器音效优先真机实录。
