# Coffee Buddy × Yeema One — Chapter 4: "One app, one fleet"
## 分镜脚本 · 时间轴结构版（对齐 UI V1.1 卡片逻辑）

> 本章目标：**机器管理**——机器主动上报异常，一句对话完成多机维护调度。全系列 B 端浓度最高的一章。
> 全部界面文案为英文（Figma 中文需出英文版）。无配音——文字 + 音效。
> 本章无飞出动效；核心画面为**机器列表卡（fleet 视图）**——系列唯一一次展示列表 UI。

---

## 0. 全局规格

| 项目 | 值 |
|------|-----|
| 画布 | 1080 × 1920（9:16） |
| 时长 | 22.0 s @ 30 fps（660 帧） |
| 结构 | 一镜到底（Agent 会话流），无剪辑 |
| 颜色 / 字体 | 取自 Figma（橙 = 需要注意 / 执行中，绿 = 在线 / 完成） |
| 缓动 | settle: cubic-bezier(0.22,1,0.36,1) · snap: cubic-bezier(0.34,1.56,0.64,1) · exit: cubic-bezier(0.55,0,1,0.45) |
| 动效规则 | 本章无飞出动效；核心动效为 fleet 列表行的**状态环实时演化**（气泡清洁动画） |
| 卡片规则 | 异常卡（机器主动推送）→ 理解 pill → 列表卡（多行状态机）→ 汇总消息 |

## 1. 时间轴

| 时间 | 画面 | 屏幕文案 / 交互 | 动效重点 | 叙事目的 |
|------|------|------|------|------|
| 0.0–1.2s | Agent 问候态 | `Hi, Alex`（打字机）／ `What would you like today?`；输入框 + 麦克风 | settle 落定 | 系列统一起始帧 |

| 3.4–5.8s | 异常卡保持可见；Alex 键盘打字 | Alex 打出：`Descale Lobby-2 at 2 AM, and deep clean Lobby-1 now.` | 键盘 whoosh + 按键音 ×40 | 一条指令调度两台机器 × 两种维护 × 两个时间点 |
| 5.8–6.4s | 黑色气泡升起 | （发送完成） | bloop | 进入解析 |

| 7.6–9.4s | 一句简短理解 pill | pill：`Deep cleaning Lobby-1 now · Descaling Lobby-2 at 02:00` | pill settle | 两个任务时间点清晰核对 |
| 9.4–12.0s | 机器列表卡（本章核心画面）：卡头 + 四行，每行 = 状态环 + 机器名 + 状态文案 | 卡头 `Your machines` + `4 online`；行1 `Lobby-1` · `Ready`（绿环）；行2 `Lobby-2` · `Needs care`（橙环，呼吸）；行3 `Lobby-3` · `Brewing · 62%`（橙环缓转）；行4 `Pantry` · `Ready`（绿环） | 四行依次落定（0.25s/行）；行3 进度环持续缓转 | 采购商最想看的一帧：fleet 状态一屏尽览；每台机器此刻在做什么 |
| 12.0–16.0s | 行1 执行深度清洁：状态环内液体上升 + 气泡上浮；行2 浮现预约 chip | 行1 状态文案 `Deep cleaning` → 完成后回 `Ready`；行2 chip：`Descale · 02:00` | 状态环清洁动画 4.0s（环内液体上升、细密气泡向上 30px 循环，橙→透明）；16.0s 环转绿；行2 chip 滑入 0.3s | 清洁过程被具象看见，不是「维护中」三个字；预约任务以 chip 形态挂在机器行上 |
| 16.0–18.0s | 行3 进度环走满；全列表转绿 | 行3 文案 `Brewing · 62%` → `Done`；四行全绿 | 环→勾 morph 0.4s | 顺带交代：fleet 里别的机器也在正常出杯——平台在同时照看所有事 |
| 18.0–20.0s | 助手汇总消息（一行） | `Done — Lobby-1 deep cleaned. Lobby-2 descales at 2 AM.` | 打字 0.8s | 对话式收尾：一句交代全部结果 |
| 20.0–22.0s | 静帧：列表卡四行全绿 | — | 细微光晕扫过列表一次后静止 | 干净结尾；全绿即平台健康的签名 |

## 3. 交接备注（给 Codex）

1. 660 帧单一 composition；分层节点：0 / 1.2 / 3.4 / 5.8 / 6.4 / 7.6 / 9.4 / 12.0 / 16.0 / 18.0 / 20.0 / 22.0。
2. 机器列表卡为复用组件（行 = 状态环 + 名称 + 位置 + 状态文案），四行各自独立状态机；状态环支持 绿/橙/进度/清洁气泡 四种形态。
3. 异常卡遵循 UX 规范「唯一处理动作」：卡内只有 `View machine` 一个按钮；本章叙事里 Alex 选择直接打字，按钮不被点击但保持可见。
4. 行3 的 `Brewing · 62%` 从入场即持续转动，12–16s 期间不被注意但始终活着——这是 fleet 的真实感来源。
5. 文案逐字锁定；帧驱动定时；机器声优先真机实录。
